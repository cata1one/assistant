# Ассистент онлайн-школы и репетитора

AI-ассистент с двумя задачами:

1. **Защита школы.** Следит, чтобы преподаватель и ученик не обменивались личными
   контактами и не договаривались заниматься или платить в обход платформы.
2. **Помощь репетитору.** После урока сам готовит конспект, словарь новых слов,
   правила, работу над ошибками, тест для самопроверки и домашнее задание:
   и то, которое озвучил преподаватель, и дополнительное по материалу урока.

Работает в четырёх вариантах: **сайт школы** (направления, заявки, личный кабинет,
доска), **Telegram-бот** для переписки учеников и преподавателей, **HTTP API** для
платформы школы и **консоль** для разбора готовых расшифровок. Уроки проходят на
**ProgressMe**, переписка — в Telegram через бота школы. Офлайн-режим
работает без внешних сервисов. Если задан ключ Claude (Anthropic API), конспект,
переводы, транскрипция, тест и задания получаются заметно богаче.

---

## Быстрый старт

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                                     # заполните нужные поля

# Разобрать готовую расшифровку урока
python -m tutor_assistant analyze examples/sample_lesson.txt --md konspekt.md

# Проверить одно сообщение
python -m tutor_assistant check "мой номер восемь девятьсот шестнадцать ..."

# Провести урок прямо в консоли
python -m tutor_assistant chat
```

Нужен Python 3.10 или новее.

## 1. Контроль контактов

Каждое сообщение проходит многоуровневую проверку (`tutor_assistant/contact_guard.py`).

| Что ищем | Примеры, которые ловятся |
|---|---|
| Телефоны | `+7 (900) 123-45-67`, `89001234567`, `8 9OO 123 45 67` (буквы вместо цифр), «восемь девятьсот шестнадцать…» (номер словами), «плюс семь…» |
| Номер по частям | `8 916` → `555` → `12 34` в трёх сообщениях подряд (скрываются все части) |
| E-mail | `ivan@gmail.com`, «ivan собака гмейл точка ком», `ivan [at] ya (dot) ru`, адрес, разбитый на сообщения |
| Ники и мессенджеры | `@ivan_petrov`, «телеграм: ivan_petrov88», «ник в телеге …», `t.me/…`, `wa.me/…`, `vk.com/…`, `instagram.com/…`, Zoom/Meet-ссылки |
| Маскировка | латиница вместо кириллицы («тeлeгрaм»), разрядка («т е л е г р а м»), невидимые символы |
| Просьбы о контактах | «мой телефон», «скинь свой номер», «напиши мне в вотсап», «пиши в личку», «найди меня в инсте», «как с тобой связаться» |
| Обход школы | «давай заниматься напрямую», «без платформы», «дешевле, чем у школы», «школа забирает половину», «только не говори школе» |
| Оплата мимо школы | «плати мне на карту», «переведи на сбер по номеру», номер карты (с проверкой контрольной суммы Луна) |

**Уровни и действия**

| Уровень | Действие | Примеры |
|---|---|---|
| `high` | **block**: сообщение удаляется, в чат уходит версия со скрытыми данными, администратор получает уведомление с исходным текстом | номер, почта, ник, ссылка на мессенджер, «давай напрямую» |
| `medium` | **warn**: предупреждение участникам, запись в журнал | «как с тобой связаться?», «без комиссии» |
| `low` | **allow**: только запись в журнал | упоминание мессенджера, фразы урока английского вроде *What's your phone number?* |

**Без ложных срабатываний на уроке.** Не блокируются: «напиши мне три
предложения», номера страниц `12 13 14 15 16`, счёт *one two three … ten*,
годы и даты, «посмотри на карту Лондона», «не переводи напрямую», ролевые
диалоги на английском. Всё это проверено автотестами.

**Белый список.** Официальные контакты школы (`TUTOR_ALLOWED_*` в `.env`)
публиковать можно.

**Конфиденциальность.** Реплики урока сохраняются уже со скрытыми данными.
Исходный текст нарушения хранится только в журнале нарушений, как доказательство
для администратора. В Claude отправляется только очищенная расшифровка.

## 2. Помощник репетитора

### Новые слова: ключевые фразы преподавателя

Ассистент сам записывает слова, когда преподаватель пишет:

```
Новые слова сегодня: apple — яблоко, pear — груша, to run - бегать, бежать
New words: kitchen [ˈkɪtʃɪn] — кухня
Запишите новые слова.            ← а дальше списком:
1. sofa — диван
2. armchair (кресло)
```

Пары распознаются и в обычной речи: «brave переводится как смелый»,
«кухня по-английски kitchen», «слово cozy — это уютный». Кроме того,
ассистент отмечает слова, которые **звучали на уроке**, но не были объявлены.
Уже изученные учеником слова в этот список не попадают.

### Домашнее задание, озвученное преподавателем

```
ДЗ: 1) упражнение 4 на с. 32; 2) выучить слова
Домашнее задание:                ← и пункты следующими сообщениями
К следующему уроку прочитайте текст на странице 20.
Homework: write 5 sentences.
```

Вопрос ученика «а какое дз?» заданием не считается.

### Отчёт после урока

* **Конспект**: тема, краткое содержание, главные тезисы.
* **Правила** с примерами: фразы «запомни», «обрати внимание», «образуется», «используется», *remember*, *we use* и т.п.
* **Работа над ошибками**: «не *I have went*, а *I have gone*», «правильно: …», *we say X, not Y*.
* **Словарь урока**: перевод, транскрипция, пример из урока.
* **Тест** с ключом ответов: выбор перевода, обратный перевод, пропуск в предложении из урока.
* **ДЗ преподавателя** (дословно) и **дополнительные задания** по материалу урока.
* **Статистика**: длительность, доля речи ученика, число нарушений.

Отчёт выводится текстом, в Markdown (`--md`) и в JSON (`--json`, API).

### Три отчёта после урока: ученику, родителям, преподавателю

Анализируется всё, что было на уроке: переписка и **расшифрованная речь**
(голосовые и запись занятия). После `/lesson_end` каждый получает свой вариант:

| Кому | Что внутри |
|---|---|
| 🎓 **Ученику** | конспект: тема, главное, правила с примерами, работа над ошибками, **🔁 что повторить к следующему уроку**, новые слова, тест (ответы — в файле), ДЗ |
| 👨‍👩‍👧 **Родителям** | что проходили (простыми словами), активность на уроке, **✅ успехи**, **⚠️ на что обратить внимание**, **💬 замечания преподавателя**, выполнено ли прошлое ДЗ и что задано, 📈 прогресс, **💡 как помочь дома** |
| 👩‍🏫 **Преподавателю** | всё вместе + ответы к тесту, статистика и копия отчёта родителям |

Что ассистент сам находит в речи преподавателя:

* **похвалу** («молодец», «отлично используешь…», *well done*) → в «Успехи». «Present Perfect» похвалой не считается;
* **замечания** («ты путаешь…», «тебе нужно подтянуть…», «отвлекаешься») → в «На что обратить внимание»;
* **проверку прошлого ДЗ** («ты не сделал домашнее задание», «домашку сделал отлично») → статус ДЗ. Фраза «проверим домашнее задание» новым заданием не считается;
* **слова для родителей** («передайте родителям, что…») → в «Замечания преподавателя»;
* **динамику**: сравнение с прошлым уроком (ошибок стало меньше или больше, ученик говорит больше, размер словаря).

**Заметки преподавателя для родителей** ученик не видит:
* `/note Миша стал увереннее, но нужно повторить времена` — в любой момент урока;
* или сообщение, начинающееся с «Родителям:» / «Для родителей:». В анонимном режиме оно не пересылается ученику, в групповом чате бот его удаляет.

Заметки тоже проверяются на контакты: передать номер «через родителей» не получится.

**Как подключить родителей:** при `/new_pair` бот сразу выдаёт третью ссылку — для родителей
(до 2 человек). Для групповых чатов или старых пар используйте `/parent_link <id пары>`.
Родитель получает только отчёты. Написать преподавателю через бота он не может, и
преподаватель не видит его аккаунт. Последний отчёт родитель может запросить словом «отчёт».

Через API: `GET /v1/lessons/{id}/report?format=student|parent`, `POST /v1/lessons/{id}/notes`.
Если задан `TUTOR_ALERT_WEBHOOK_URL`, после урока платформа получает событие `lesson_finished`
с конспектом ученика и отчётом родителям. Его можно переслать по почте, в личный кабинет или SMS.
В консоли: `analyze урок.txt --for parent|student --parent-md otchet.md`.

С ключом Claude отчёты пишет модель (тактично, конкретно, без внутренних дел школы).
Заметки преподавателя при этом сохраняются дословно. Без ключа отчёты собираются офлайн
по тем же сигналам.

### Запросы по ключевым словам

Короткие сообщения в чате и в консоли:

| Запрос | Ответ |
|---|---|
| «новые слова сегодня», «какие слова мы сегодня выучили» | слова за сегодня |
| «новые слова» | слова текущего или последнего урока |
| «мой словарь» | все слова ученика |
| «дз», «домашнее задание», «что задали» | домашнее задание |
| «конспект», «что мы прошли» | конспект |
| «тест» / «ответы» | тест / ключ ответов |
| «отчёт» | полный отчёт |
| «помощь» | справка |

## Сайт: BetterTeach и BetterStudy

Сайт раздаётся тем же сервером, что и API:

```bash
python -m tutor_assistant serve        # бот + сайт + API, сайт: http://127.0.0.1:8080
python -m tutor_assistant api          # только сайт и API (без бота)
```

Один продукт с двумя лицами. Преподаватель и школа видят **BetterTeach** (коралловый),
ученик и родитель — **BetterStudy** (синий). Бренд переключается сам по роли вошедшего.

**Вход.** Регистрация по почте и паролю, Telegram не обязателен. Пароли хранятся как
PBKDF2-SHA256 (200 000 итераций). Попытки входа ограничены: не больше 10 за 15 минут.
Старый вход по ссылке из бота (`/cabinet`) тоже работает. Telegram можно привязать
в профиле: тогда уведомления дублируются туда.

**Роли:**

| Роль | Что может |
|---|---|
| Репетитор | Ученики по ссылкам-приглашениям, урок с видео и доской, материалы, ДЗ, переписка с учениками и родителями, поиск учеников |
| Ученик | Уроки и конспекты, ДЗ с ответом, карточки слов с интервальным повторением, словарь, доски, сообщения, поиск преподавателя. Сам урок и доску **не начинает** |
| Родитель | Отчёты на сайте, ДЗ, сколько слов выучено. Пишет преподавателю, а если преподаватель из школы — ещё и школе. Видит только имя преподавателя |
| Онлайн-школа | Пул преподавателей (приглашение по ссылке) и их учеников, уроки и отчёты, сигналы о попытках обменяться контактами, общая база материалов, переписка с родителями, переключатель фильтра |

**Частный репетитор и репетитор школы.** Частный репетитор работает сам: его переписка,
речь и доска **не фильтруются**. Репетитор, пришедший по приглашению школы, работает под
контролем школы. Контакты блокируются (если школа не выключила фильтр), а попытки
обменяться ими приходят сигналом владельцу школы. Пары из Telegram-бота всегда строгие.

**Доска.** Доска сделана на DOM. Объекты: заметки, текст, ручка, маркер, фигуры, стрелки,
картинки, файлы, ссылки и видео. Их можно перемещать, растягивать и редактировать двойным
щелчком. Есть отмена, масштаб, «показать всё» и жесты на телефоне.

Стикеры собраны в наборы: Хэллоуин, Новый год, китайский Новый год, похвала (в том числе
«加油!» и «太棒了!»), школа, погода, а также эмодзи-наборы. Стикеры нарисованы для проекта
(SVG), чужие картинки (например, из Pinterest) не используются. Свою картинку можно загрузить.

Видео из **VK Видео, YouTube и Rutube** встраивается прямо на доску: демонстрация экрана
не нужна. Очищать доску и загружать на неё файлы может только преподаватель.

**Материалы.** Файлы (PDF, картинки, презентации, документы, аудио, видео — до 25 МБ)
можно перетаскивать пачкой. Ссылки и видео добавляются отдельно. Чтобы перенести материалы
с ProgressMe, выгрузите их оттуда файлами и перетащите все разом. Автоматического импорта
из ProgressMe нет. Файлы отдаются по секретному адресу, картинки проверяются по сигнатуре,
SVG не принимается.

**Карточки.** Новые слова урока попадают в словарь и в карточки. Повторение идёт по SM-2:
«не помню» — через 10 минут, дальше 1 и 3 дня, потом интервал × лёгкость.

**Конструктор занятий (как на ProgressMe).** Раздел «Занятия» у преподавателя и школы.
Типы заданий:
- вставка слов в текст — правильный ответ пишется в квадратных скобках, варианты через «|»: `I [have been|'ve been] to London`;
- пары «слово — значение»;
- тест с вариантами ответа;
- аудирование — аудиофайл или бесплатная озвучка текста браузером, плюс пропуски и вопросы;
- новые слова, текст или правило, свободный ответ, видео.

Занятие выдаётся как домашнее задание. Ответы проверяет сервер, ученику они не приходят заранее. Слова
занятия сразу попадают в карточки ученика.

Готовая библиотека (`tutor_assistant/library.py`, тексты собственные):
- IELTS Speaking, Writing Task 1 и Listening;
- HSK 1 и HSK 2;
- Present Perfect.

Создать занятие можно тремя способами:
- **без ИИ** — из слов и текста преподавателя (пары, пропуски, тест, аудирование);
- **с ИИ** — по теме, когда ИИ подключён;
- вручную.

**Конспект урока от ИИ (необязательно).** Без ИИ конспект, слова и ДЗ собираются офлайн-алгоритмом.
С ИИ по расшифровке урока получаются:
- связный конспект и главное, что было сказано;
- новые слова с переводом и примерами;
- домашнее задание;
- тест;
- отчёт родителям.

Слова сразу попадают в карточки ученика, а преподаватель может отредактировать весь отчёт. Бесплатная
модель на сервере без видеокарты думает 5–15 минут. Поэтому урок завершается сразу: ученик видит
черновик, а готовый конспект приходит, когда ИИ закончит. Если преподаватель успел поправить отчёт,
ИИ его правки не перезаписывает.

Включить бесплатный ИИ на своём сервере одной командой (ставит Ollama и подбирает модель Qwen 2.5
по объёму памяти: от 4 ГБ — 3b, от 8 ГБ — 7b, от 16 ГБ — 14b):

```bash
sudo bash /opt/better-study/deploy/enable-ai.sh        # выключить: enable-ai.sh --off
```

Или вручную — любой OpenAI-совместимый сервис, строки для `.env`:

```bash
# Ollama на своём сервере — бесплатно и без внешних сервисов, нужно ~8 ГБ свободной памяти:
#   curl -fsSL https://ollama.com/install.sh | sh && ollama pull qwen2.5:7b
TUTOR_AI_URL=http://127.0.0.1:11434/v1
TUTOR_AI_MODEL=qwen2.5:7b
# или OpenRouter: ключ на openrouter.ai, модель из списка с фильтром Free (название с «:free»)
# TUTOR_AI_URL=https://openrouter.ai/api/v1
# TUTOR_AI_KEY=...
# TUTOR_AI_MODEL=...:free
```

Если задан ключ Anthropic, вместо этого используется Claude. Если ИИ не ответил, занятие собирается без ИИ.

**Домашка, слова, отчёты.**
- Ученик прикладывает к ДЗ фото тетради или скриншот: кнопкой, перетаскиванием или Ctrl+V.
- Слова из ДЗ («Новые слова: apple — яблоко, …»), из поля «Новые слова» и из занятий сразу становятся карточками.
- Преподаватель добавляет и убирает слова ученика (раздел «Ученики» → «Слова»). Ученик может убрать лишнее слово из своего словаря.
- Преподаватель правит задания и отчёты после урока. Правка слов в отчёте меняет карточки ученика.

**Тарифы.** Старт — 0 ₽ (до 3 учеников), Про — 690 ₽ (до 30), Безлимит — 990 ₽,
Школа — 490 ₽ за преподавателя. **Онлайн-оплата не подключена:** сервер ограничивает только
число учеников, а тариф пока меняется вручную в базе (`accounts.plan`).

**Сборка.** React, Tailwind CSS и lucide-иконки. Шрифты Manrope и Inter встроены в сборку.
Тяжёлых анимаций и плавного скролла нет, страницы грузятся по требованию. Исходники лежат
в `frontend/`, готовая сборка — в `tutor_assistant/web/`, поэтому Node.js на сервере не нужен:

```bash
cd frontend && npm install && npm run build    # пересобрать tutor_assistant/web
```

**Заявка с биржи.** Контакт из заявки видит только администратор. Когда ученик выбирает
преподавателя, он получает ссылку на регистрацию на сайте, а также в Telegram, если бот
настроен.

**Безопасность:**
- строгая политика CSP: свои скрипты, из внешних фреймов — только VK, YouTube и Rutube;
- запрет встраивания сайта в чужие страницы;
- токены хранятся хешами;
- ссылка не утекает через Referer.

Для работы в интернете поставьте перед сервером Caddy или nginx с HTTPS (`deploy/install.sh`)
и задайте `TUTOR_TRUST_PROXY=1`. **Камера и микрофон в браузере работают только по
https://**, поэтому для видеоуроков нужен домен.

## Чат, кабинет родителя, отзывы и биржа учеников

**Один сайт для взрослых и детей.** Вверху главной есть переключатель «Взрослым / Детям и подросткам».
Он меняет заголовок, преимущества, направления и каталог курсов и запоминается в браузере.
У каждого курса в `catalog.py` указано, для кого он: `audience: ["adult", "kid"]`.

**Чат с преподавателем вне урока** — вкладка «Сообщения» в кабинете.
- История общая с Telegram-ботом: что написано на сайте, приходит собеседнику в Telegram,
  а ответы из Telegram видны на сайте.
- Проверка на контакты та же, что в боте. Номер, разбитый между сайтом и Telegram, тоже ловится.
- Во время урока сообщения из чата идут в конспект: из них берутся слова и ДЗ.

**Кабинет родителя.** Родитель подключается по ссылке из `/new_pair` или `/parent_link`. В кабинете видны:
- сводка по ребёнку: число уроков и слов в словаре, дата последнего урока;
- тема последнего урока и успехи, на что обратить внимание и домашнее задание;
- все отчёты по урокам.

Каждый отчёт также приходит родителю в Telegram.

**Отзывы.** Ученики, родители и преподаватели оставляют отзыв в кабинете (вкладка «Отзыв о школе»).
На сайте он появится только после одобрения администратором (вкладка «Отзывы»).
Выдуманные отзывы как настоящие публиковать нельзя: это нарушение закона о рекламе и прав
потребителей. Поэтому вместо них есть примеры с пометкой «пример» (`TUTOR_DEMO_REVIEWS=1`). Они
пропадают, как только появляется первый настоящий отзыв, и не входят в средний рейтинг.

**Биржа учеников** (`#/market`). Школа остаётся посредником: контакты не раскрываются.
1. **Ученик или родитель** бесплатно размещает заявку. В ней: имя, возраст, для кого занятия, язык,
   направление, уровень (начальный, средний или продвинутый), цели, какого преподавателя ищет,
   расписание, бюджет за урок и комментарий.
   - Публично видны только имя и описание задачи. Телефон видит только школа.
   - Тексты заявки проверяются: контакты в них оставить нельзя.
2. **Проверенные преподаватели** откликаются: пишут, как будут заниматься, и называют свою цену.
   - Проверенным считается преподаватель действующей пары или тот, чью анкету одобрил
     администратор. Анкету создают командой `/teacher Имя` в боте.
   - Контакты в отклике блокируются, а нарушение уходит администратору.
3. **Ученик выбирает** преподавателя на своей странице. Ссылка на неё хранится в браузере,
   её можно скопировать.
   - Система сама создаёт анонимную пару в боте и выдаёт ученику ссылку на чат, для ребёнка — ещё
     и ссылку для родителя.
   - Преподаватель и администратор получают уведомления.

Чем биржа выгодна:
- **ученикам** — бесплатно, есть выбор и цены, преподаватели проверены, личные данные не раскрываются;
- **преподавателям** — ученики с понятной задачей без затрат на рекламу, своя цена, онлайн-класс
  и отчёты родителям готовятся автоматически, комиссия школы только с оплаченных уроков
  (`TUTOR_MARKET_FEE`).

Защита от спама:
- не больше 3 заявок в сутки с одного IP;
- скрытое поле-ловушка для ботов;
- обязательное согласие на обработку данных.

## Онлайн-класс: урок прямо на сайте школы

Видеоурок проходит в браузере, без ProgressMe, Zoom и сторонних сервисов. Всё, что
сказано и написано на уроке, расшифровывается, проверяется на контакты и попадает
в отчёт в Telegram.

**Как провести урок:**

1. Преподаватель открывает кабинет (`/cabinet` в боте) и нажимает **«Начать урок в
   онлайн-классе»**. Ученику в Telegram сразу приходит ссылка на класс.
2. Оба нажимают **«Войти в класс — я согласен с записью»**. В классе есть видео, чат,
   общая доска урока и показ экрана.
3. Преподаватель нажимает **«Завершить урок»**. Конспект, слова, тест и ДЗ уходят ученику
   в Telegram, родителям — отчёт об успехах, преподавателю — полный отчёт. Всё это
   сохраняется и в кабинете.

Урок можно начать и командой `/lesson_start` в боте: в сообщении появится кнопка
«Онлайн-класс школы».

**Запись и расшифровка.** Каждый участник записывает **свой** микрофон фрагментами по
15 секунд, и фрагменты сразу уходят на сервер. Поэтому в расшифровке всегда известно,
кто говорит. Сервер расшифровывает речь (локальный Whisper, `requirements-speech.txt`).
Расшифровка видна в чате урока с пометкой 🎙 и идёт в конспект: оттуда берутся новые
слова, ДЗ, правила и замечания.

**Контроль контактов** работает в трёх местах:
- **речь:** номер, продиктованный на стыке двух фрагментов, тоже ловится;
- **чат:** сообщение с контактом скрывается у обоих;
- **текст на доске:** контакт на доску не попадает.

Каждое нарушение сразу приходит администратору в Telegram (`TUTOR_ADMIN_CHAT_ID`) и
сохраняется в журнале с исходным текстом. Запись обязательна: если её нет или в ней
долгий перерыв (`TUTOR_RECORDING_GAP_SECONDS`), это тоже нарушение.

**Что нужно для работы:**

- **HTTPS.** Браузеры дают доступ к камере и микрофону только на https:// (или на
  127.0.0.1 для проверки).
- **TURN-сервер.** Видео идёт напрямую между браузерами. Обычно хватает публичных STUN,
  но часть мобильных и корпоративных сетей пропускает видео только через TURN-сервер.
  Поставьте coturn на сервер школы и укажите его в `TUTOR_ICE_SERVERS`.
- **Распознавание речи на сервере** (`pip install -r requirements-speech.txt`). Без него
  запись учитывается, но речь не расшифровывается и не проверяется, о чём класс
  предупреждает преподавателя.

**Честные ограничения:**

- Сказанное вслух собеседник уже услышал. Система не может «отозвать» речь, но фиксирует
  нарушение в течение 15–30 секунд и сообщает администратору.
- Если показать номер на листке в камеру или нарисовать его на доске от руки, система
  этого не распознает.
- Если участник выключит микрофон, его не слышит и собеседник, поэтому передать контакт
  голосом так нельзя.

## Telegram-бот: анонимный режим (рекомендуется)

В обычной Telegram-группе участники **всегда** видят профили друг друга (имя,
@ник, аватар) и могут написать в личку. Боты это отключить не могут.
Поэтому для полной защиты используйте **анонимный мост**: преподаватель и ученик
не состоят в общем чате, каждый пишет только боту, а бот пересылает сообщения
от своего имени под псевдонимом.

```
Преподаватель ──► 🤖 бот школы (проверка) ──► Ученик
  видит: «Миша: …»                          видит: «Анна Петровна: …»
```

**Что получает собеседник:** только псевдоним, который задала школа, и текст сообщения.
Имя аккаунта, @ник, аватар, номер телефона и id не передаются никогда.

**Как подключить:**

1. Укажите свой Telegram id в `TUTOR_ADMIN_USER_IDS` (узнать id можно у @userinfobot) и запустите бота.
2. В личке с ботом отправьте `/new_pair Анна Петровна | Миша`. Бот пришлёт две одноразовые ссылки.
3. Отправьте ссылку преподавателю и ссылку ученику по каналам школы (почта, личный кабинет).
4. Участники открывают ссылки и просто пишут боту. Преподаватель ведёт урок командами `/lesson_start` и `/lesson_end`, конспект и тест получают оба.

**Защита в этом режиме:**
* сообщения с контактами **не доставляются**, администратор получает уведомление с реальным аккаунтом нарушителя;
* если номер отправили по частям, уже доставленные части удаляются у собеседника;
* скрытые ссылки в тексте и упоминания аккаунтов вырезаются и проверяются;
* карточки контактов («Поделиться контактом»), геолокация и опросы не пересылаются;
* отредактированные сообщения не пересылаются: собеседник видит только проверенную исходную версию;
* фото, файлы и голосовые пересылаются, но их содержимое автоматически не проверяется. Чтобы передавать только текст, задайте `TUTOR_RELAY_MEDIA=0`.

Если у преподавателя несколько учеников, выбрать собеседника можно командой `/chats`.
Кроме того, можно ответить (reply) на сообщение нужного ученика.
Администратор: `/pairs` показывает список пар, `/unpair <id>` отключает пару.

**Дополнительно ученику** (по желанию) стоит закрыть номер в настройках Telegram:
Настройки → Конфиденциальность → Номер телефона → «Никто».

## Telegram-бот: групповой чат

1. Создайте бота у [@BotFather](https://t.me/BotFather) и запишите токен в `TELEGRAM_BOT_TOKEN`.
2. В @BotFather: `/setprivacy` → **Disable**, иначе бот не видит обычные сообщения в группе.
3. Добавьте бота в чат урока **администратором с правом «Удалять сообщения»**.
4. Укажите `TUTOR_ADMIN_CHAT_ID`: туда будут приходить уведомления о нарушениях.
5. Запуск: `python -m tutor_assistant bot`.

Команды: `/lesson_start [тема]`, `/lesson_end`, `/words`, `/words_today`,
`/dictionary`, `/homework`, `/test`, `/answers`, `/summary`, `/report`, `/note <текст>`, `/parent_link`,
`/check <текст>`, `/incidents` (только для администраторов), `/help`.

* Контакты блокируются в чате **всегда**, а не только во время урока. Проверяются и отредактированные сообщения, и подписи к файлам.
* Завершить урок может только преподаватель (тот, кто его начал) или администратор чата.
* В личке боту можно прислать расшифровку урока текстом или файлом `.txt` (UTF-8 или Windows-1251). В ответ придут отчёт и список нарушений.

## Запись и расшифровка урока

Когда начинается урок, включается контроль речи. Цель — чтобы преподаватель
не передал контакты голосом.

```
🎙 речь урока ──► фрагменты по 15 с ──► расшифровка (локальный Whisper) ──► проверка на контакты
                                                                            ├─ найдено → нарушение + уведомление администратору
                                                                            └─ чисто  → в расшифровку урока → конспект, слова, ДЗ
```

**Установка распознавания речи** (один раз, на сервере школы):

```bash
pip install -r requirements-speech.txt
```

Речь распознаётся **локально** моделью Whisper (пакет faster-whisper), аудио
никуда не отправляется. При первом запуске модель скачивается (`small`, около 500 МБ),
для серверов без интернета задайте папку с моделью в `TUTOR_STT_MODEL_DIR`.

**Что проверяется:**

| Источник | Как работает |
|---|---|
| Голосовые и «кружочки» в Telegram | Расшифровываются **до** пересылки. С контактами сообщение не доставляется, администратор получает расшифровку |
| Видеозанятие (Zoom, Meet, Телемост, своя платформа) | Программа записи на компьютере преподавателя или серверная запись платформы отправляет звук фрагментами в API, нарушение видно через несколько секунд |
| Готовая запись урока (mp3, m4a, mp4…) | `python -m tutor_assistant analyze запись.mp3`: расшифровка, проверка, конспект |

Ловятся и продиктованные вслух контакты: «восемь девятьсот шестнадцать…»,
«иван точка петров собака джимейл точка ком», «ник анна нижнее подчёркивание тьютор».
Номер, разорванный между двумя фрагментами записи, тоже распознаётся.

### Обязательная запись урока

С `TUTOR_REQUIRE_RECORDING=1` при `/lesson_start` бот объявляет о записи и
показывает команду для её включения:

```bash
python -m tutor_assistant record --lesson <id урока> --api https://сервер-школы --token <токен>
```

Программа записывает микрофон (`--list-devices`, `--device N` выбирают устройство)
и каждые 15 секунд отправляет фрагмент. Если звука нет дольше
`TUTOR_RECORDING_GAP_SECONDS` (90 с), например запись не включили или выключили
посреди урока, преподаватель получает напоминание, а администратор — уведомление
о нарушении. Состояние записи показывает команда `/recording`.

Установка программы записи на компьютер преподавателя: `pip install -r requirements-recorder.txt`.

**Важно про надёжность.** Программу на своём компьютере преподаватель может не запустить
или подменить звук. Контроль перерывов это фиксирует, но лучше всего записывать звук
**на стороне платформы видеосвязи** (серверная запись Zoom, LiveKit, Jitsi и т.п.) и
отправлять его в `POST /v1/lessons/{id}/audio` отдельно для каждого участника.
Тогда отключить запись нельзя, а говорящие различаются. Чтобы программа записывала
обоих собеседников, выберите устройство, которое захватывает звук системы:
«Стерео микшер» в Windows, BlackHole в macOS, monitor-источник в Linux.

**Согласие на запись.** При старте урока бот предупреждает участников о записи.
Добавьте пункт о записи и автоматической проверке занятий в договор-оферту школы
и в согласие на обработку персональных данных.

Если распознавание речи не установлено, голосовые сообщения **не пересылаются**
(безопасный режим). Чтобы пересылать их без проверки, задайте `TUTOR_RELAY_UNCHECKED_AUDIO=1`.

## HTTP API для платформы школы

```bash
python -m tutor_assistant api --host 0.0.0.0 --port 8080
```

Авторизация: `Authorization: Bearer $TUTOR_API_TOKEN`.

| Метод | Путь | Тело / параметры |
|---|---|---|
| GET | `/health` | — |
| POST | `/v1/moderate` | `{"text"}` → `action`, `severity`, `redacted_text`, `findings` |
| POST | `/v1/lessons` | `{"chat_id","tutor_id","tutor_name","student_id","student_name","title"}` |
| GET | `/v1/lessons/{id}` | — |
| POST | `/v1/lessons/{id}/messages` | `{"speaker_id","speaker_name","role":"tutor\|student","text","message_id"}` |
| POST | `/v1/lessons/{id}/finish` | `{"use_llm": true}` → полный отчёт |
| GET | `/v1/lessons/{id}/report` | `?format=json\|text\|markdown` |
| POST | `/v1/analyze` | `{"transcript","title","student_id","use_llm","save"}` |
| GET | `/v1/students/{id}/words` | `?date=today\|YYYY-MM-DD` |
| GET | `/v1/incidents` | `?lesson_id=&user_id=&limit=` |
| POST | `/v1/lessons/{id}/audio` | тело — аудиофрагмент (wav/ogg/webm/mp3), `?speaker_id=&speaker_name=&role=` → расшифровка и проверка |
| POST | `/v1/analyze/audio` | тело — запись урока целиком, `?title=&student_id=&use_llm=&save=` |

При создании урока можно передать `"require_recording": true`, и в ответе придёт
`recording.upload_url`, куда отправлять звук. Если задан `TUTOR_ALERT_WEBHOOK_URL`,
о каждом нарушении (в тексте, в речи, перерыв записи) сервер сразу отправит JSON на этот адрес.

Пример:

```bash
curl -H "Authorization: Bearer $TUTOR_API_TOKEN" -d '{"text":"пиши мне в вотсап"}' \
     http://127.0.0.1:8080/v1/moderate
```

Ответ на сообщение урока содержит `moderation.action` (`allow`/`warn`/`block`),
`redacted_text` (что показать в чате) и `related_message_ids`: id предыдущих
частей номера, которые тоже нужно скрыть.

## Формат расшифровки урока

```
[10:00] Анна Петровна (преподаватель): Тема урока: Present Perfect.
[10:01] Миша (ученик): Здравствуйте!
Учитель: …        Ученик: …        Teacher: …        Student: …        T: …  S: …
```

Строка без «Имя:» продолжает предыдущую реплику. Если роли не подписаны,
преподавателем считается тот, кто говорит больше, а точнее их можно задать
так: `--tutor "Анна" --student-name "Миша"`. Пример: `examples/sample_lesson.txt`.

## Claude (необязательно)

С ключом `ANTHROPIC_API_KEY` (режим `TUTOR_LLM=auto`) отчёт готовит модель
`claude-opus-5-5`. Ответ приходит в строгом JSON-формате и проверяется
pydantic-схемой. Включён серверный резерв (`fallbacks: "default"`): если модель
отклонит запрос, его выполнит резервная модель. Слова и ДЗ, которые озвучил
преподаватель, сохраняются всегда, Claude только дополняет их переводом,
транскрипцией и примерами. При любой ошибке API (нет ключа, нет сети, лимиты)
отчёт строится офлайн, а в нём появляется пометка о причине.
